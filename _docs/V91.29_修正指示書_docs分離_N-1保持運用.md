ベース: V91.28（attributable固定・3Q撤去・ポインタ式ランチャー版）
対象: 配布パッケージ構成（コード変更なし）/ 差し替え運用手順書の改訂
実測: パッケージ3.5MBのうち docs が2.1MB・119ファイル（約60%）。
      docsはV13〜V91の開発ノートで、コードから参照されていないことを
      確認済み（src・Start-YakuLingo.ps1 に docs 参照なし）。

## 1.【必須】docs をバージョン配布物から分離

### 方針
開発ノート履歴は削除せず、**共有ルート直下の1箇所に集約**する
（ポートフォリオ資産として履歴に価値があるため、削除ではなく移設）。

### 変更後の構成
```
…\ECM資料英訳ツール\
    YakuLingo起動.vbs
    current.txt
    _docs\              ← 開発ノート集約（バージョン非依存・1部のみ）
        ARCHIVE_V13-V91\   ← 既存119ファイルをここへ移設
        （以後の修正指示書・開発ノートもここに追加）
    V91.28\
        app\ ...        ← docs を含まない
    V91.29\
        app\ ...        ← docs を含まない
```

### 作業
1. V91.28\app\docs の119ファイルを ルート `_docs\ARCHIVE_V13-V91\` へ移設
2. ビルド（ZIP作成）手順に「app\docs を含めない」を明記。README.md /
   DESIGN.md はバージョンフォルダに残す（軽量かつ利用者向け）
3. 効果: パッケージ 3.5MB → 約1.4MB（−60%）。N-1運用時の共有占有は
   現行比で 7.0MB → 2.8MB＋_docs 2.1MB（1部のみ）
