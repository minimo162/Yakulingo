## 3. 未解決の技術的問題 ―― 判定の反転（3周目）

xlsx の書き戻しで、**訳していないセルの書式が、本文を1バイトも変えずに消える**（以下「被害D」）。
守りの検出器 `Get-YakuXlsxRunCells`（`src/SheetLayout.ps1`）が
「部分書式を持つセル」を列挙し、そのセルを含む一括箱を捨てる作りだった。

**列挙は2回続けて破れた。**

1周目: `t="inlineStr"` の `<is><r><rPr>` を見ていなかった
2周目: さらに3つ（すべて実測。**Excel が描くのに検出器は0件**）

```
(1) <is><t>MIXED</t><r><rPr><b/></rPr><t>BOLDPART</t></r></is>
    <t> と <r> の混在。直下の <r> しか集めないため run が1つになり捨てられる。
    共有文字列側でも同じ。
(2) <c r='E2' s='0' t='s'>   単引用符の属性。正規表現が二重引用符固定。
(3) <rPh>（ふりがな）が消える。 ← Excel 自身が書く形。いちばん重い
    実測: value=東京 phonetics=1 text=トウキョウ → 書込後 phonetics=0 text=<empty>
```

**利用者判断（2026-08-16）: 判定を反転する。**

```
いま  リッチだと分かったセルを箱から外す      → 見落としたら壊す
反転  平文だと証明できたセルだけ箱に入れる    → 見落としたら遅くなるだけ
```

「平文と証明できる」は狭く: 共有文字列で `<si>` の直下が `<t>` 1つだけ・`<r>` なし・
`<rPh>` なし・他の子要素なし／共有文字列でもインライン文字列でもないセル。
**それ以外は全部「証明できない」**。

前例: `Test-YakuExcelComFalse` は `DBNull` を「偽と確定していない」として安全側へ倒す。
数式集合が読めなければ箱を捨てる（`FileProcessors.ps1` `reason=formula-set-unknown`）。

**注意: 出力は2つ要る。** (a) 除外集合（箱の脱出口が使う）と (b) run の中身
（訳文を書いたセルを支配的書式へ揃えるのに要る）。一緒くたにすると反転が成立しない。

## 5. Smartcat を実機で測って分かったこと（公開資料に無い）

- 取り込み既定: **非表示のセル・シートを取り込まない**／シート名を取り込まない／
  コメントを取り込まない／図形の文字は取り込む
- **非表示は訳さず・消さず・触らず素通し**（書き出したファイルに `state="hidden"` も
  `hidden="1"` も残り、取り込まなかった文字列は原形のまま）
- **セル内の部分書式は番号つきタグ対**として原文セグメントに現れる。訳者が任意の位置へ置く。
  位置も長さも違う訳文で往復し、太字は指定した語にだけ載った
- タグの QA は **警告＋IGNORE**（「Tag placed in the middle of word」）。確定を止めない
- **未確定セグメントは原文のまま出力される**
- **訳文の書体を黙って `MS Gothic` へ差し替える**（1語も訳していなくても）。
  公開資料は「フォント差し替え機能は無い」としているが実装はやっている
- 生成エンジンは `Aspose.Words for .NET 24.11.0`
- **プロジェクト一覧からの一括ダウンロードは拡張機能経由では発火しない。**
  エディタ右上のダウンロードは通る
- **裏のタブでは読み込みが起きない。** 前面に出す必要がある（利用者の指摘）

Word（docx）は **1段落でもタブ・改行・リンク・図・変更履歴・複数書式があると文書ごと
出力しない**。実在の Word 29本・1,283段落で378段落が却下、本文のある26本中
出力できたのは1本（ただし大半が Office 付属テンプレートで、業務での頻度ではない）。

## 7. 今日踏んだ落とし穴（**すべて自分の道具の側だった**）

- **PowerShell の別名衝突を3回踏んだ。** `R` = `Invoke-History`、`CP` = `Copy-Item`、
  `Cp` = `Copy-Item`。使い捨てスクリプトの補助関数は**長い名前**にする
- **使い捨て `.ps1` のコメントに日本語を書いて壊した。** BOM が付かないので
  そこで解析がずれ、後続行が黙って空になる。**ASCII のみ。日本語は符号位置から組み立て、
  使う前に印字して長さを検算する**
- **`<c\b[^>]*>.*?</c>` は自己終端の `<c/>` を飲み、次のセルの中身を盗む。**
  自己終端の枝を先に置く（コミット `38dadab`）
- **`<b/>` と `<b />` を同じ正規表現で数えようとして「太字が消えた」と誤読した。**
  生の XML を見れば残っていた。**数えるな、比べろ**
- **ログの `items=1` を一括の大きさと誤読した。** 実体は
  `CAT numeric masking. items=1 maskedItems=1`。**どの記録の一部かを確かめてから読む**
- **`elapsedMs` を全行から拾って中央値220msを出した。** `Copilot wait result` の行に
  絞ると中央値2,222ms。**母集団を確かめる**
- **Smartcat のエディタが「Loading data...」で止まるのを製品の不具合と読みかけた。**
  原因は裏のタブに置いていたこと
