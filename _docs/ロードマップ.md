## §0 次の一手

**利用者の通常ログオンセッションで、更新後の資料翻訳からWord・ExcelのDRAFTを1件ずつ作る。**

一つの起動ファイル→用途を説明する開始画面→`ちょっと翻訳`／`資料翻訳`の分離は実装済み。
ちょっと翻訳は保存・cache・TM・コーパス・過去例・本文診断を使わない。資料翻訳だけが
作業を保存し、出典付き候補を手動挿入できる。旧共有画面とDOM/base64引継ぎは削除した。

実機では、`売上高は一億二千万円でした。`をCopilotへ送り、`Net sales were 120 million yen.`
を取得し、server artifactで資料翻訳へ未確認のまま移し、確認済み訳文の出力まで通した。
次はExcel COMを利用できる通常ログオンセッションで、Word/Excel取込、編集直後の保存barrier、
全行確認、DRAFT書戻し、再起動後の再開を確認する。

**そのとき一緒に見るもの（2026-08-10 のUI/UX改修）**: 翻訳中に出る「残り○分ほどです」、
「翻訳をやめる」、完了時のタスクバー表示、そして「⚠ 保存できませんでした」の行表示。
いずれも自動試験では実データが出ないので、実機で1回流さないと確認できない。

完成Word/Excelを外部公表可能成果物と呼ぶのはHorizon 3以降。

**出力の線引きは 2026-08-10 に利用者判断で変わった。** 従来は全文確認を通るまで何も取り出せず、
細切れで使うと成果がゼロになっていた。いまは3種類ある。

| 出口 | 条件 | 中身 |
| --- | --- | --- |
| 確認済みの行だけコピー | 確認済みが1行以上 | reviewed かつ QC が最新の行だけ。含めなかった行数を画面に必ず出す |
| 確認済み訳文 | 全行が確認済み | 従来どおり |
| 確認用DRAFT（社外配布不可） | 全行が確認済み＋体裁保証 | 従来どおり。**ファイル書き戻しの全行要件は緩めていない** |

### §5-3 課題4（英文短信・英文有報）を「翻訳」として解くこと

いまのアプリでは成立しない。足りないのは訳の質ではない。

| | |
| --- | --- |
| 入口 | 扱えるのはテキスト貼り付けと `.xlsx/.xlsm/.csv` だけ。短信・有報は Word・HTML・PDF・XBRL |
| 出口 | Excel か画面のコピー。短信の様式へ戻す道が無い |
| 文体 | 公表体の軸は 2026-08-08 に畳んだ。CAT は逆に常に社内の電文体 |

**材料の側はむしろ揃っている。** 3,001組のうち 2,582組（86%）が決算短信、

中身の大半は課題4の材料になる。

### §5-4 付き合うしかない制約

- **Copilot に弾かれることがある** — 短時間に集中して送ると、しばらく全滅する。
  間を置けば戻る。

  ログから数えた事実（2026-08-07 19時〜2026-08-08 19時、送信545回）。
  **最初の失敗は184回目**であって、以前ここに書いていた「121回」ではない。

  | 時刻帯 | 送信 | 成功 | 「問題が発生」 |
  | --- | ---: | ---: | ---: |
  | 08-08 05 | 140 | 122 | 0 |
  | 08-08 06 | 21 | 0 | 18 |
  | 08-08 09 | 7 | 7 | 0 |
  | 08-08 10 | 111 | 96 | 0 |
  | 08-08 11 | 26 | 0 | 38 |
  | 08-08 12 | 35 | 30 | 0 |

  以降 19時まで毎時20〜35回で、7時間連続して全滅なし。

  **確かめていないこと**: 窓の長さ、境目の回数、回復が時間経過によるものか
  送信間隔によるものか。当たった2点（140・111）と当たらなかった点（20〜35）が
  あるだけである。

  **利用者の見立て**（未確認）: 同じ M365 アカウントで別のアプリが同時に画像を
  Copilot へ送っていたことが効いていた可能性がある。画像の送信をやめてからは
  弾かれていない。どちらの筋でも「短時間に集中させない」方針は変わらない。

  **「アプリ側の問題ではない」は「対処もアプリ側に無い」を意味しない**（§4-5）
- **Edge の凍結** — 18分のアイドル後にページ層だけが応答しなくなる。再現条件を掴めていない。
  外部から CDP を突く方法は使えない（1ページ1クライアント）。
  試していない手が1つある: 起動フラグにスリープタブを止めるものが入っていない

- **転置索引** — 実測して捨てた（`V91.61_段階2_コーパス検索.md`）

  なる（10倍）。換算を入れるまで選択肢から外してある

## §9 作業の進め方

`CLAUDE.md` に決まりがある。**悪い結果が出たら、まず自分の道具を疑う。**

そのうえで、この文書に固有のもの:

- **画面は開いて押す。** 構文検査と回帰テストが通り抜けた不具合が、今日5件（§6の下）
- **指標を作ったら、その指標が拾った実物を数件見る**
- **件数を根拠にしない。** 用語はどちらかに統一されるので、出現回数は
  「その語が何回話題になったか」でしかない

### 検査を通り抜けた不具合の型（2026-08-08）

単体は全部動いていて、壊れているのは**繋ぎ目**だった。

| 何が壊れていたか | なぜ通り抜けたか |
| --- | --- |
| 突き合わせボタンが押した瞬間に落ちる（`yakuPostJson` 未定義） | 同期例外で catch に入らず、「数分かかります」が失敗を隠した |
| 候補ペインがマウスで押しても無反応 | focusin が click より先に走り、現在行の印が消えていた |
| 簡易翻訳から CAT へ渡すとき訳文が捨てられる | 単体はどちらも動く |
| 翻訳方向が黙って逆になる | ラジオは「自動」のままなのに、そこを見ていた |
| CAT のボタンが準備前に無反応 | 条件に合わないと何も言わずに戻っていた |
| **CAT が実数値と人名を素のまま送っていた** | マスクが**呼び出し元0件の関数**にあり、検査はそのファイルを grep していた |

最後の1件が最も重い。**検査が、閉じようとした穴と同じ形の穴を持っていた。**
いまは中継関数を「自分で伏せるもの」と「呼び出し側に任せるもの」に分けて見ている。
