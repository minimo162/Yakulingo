## 1.【必須】原文が与えた略称はBRIEFで単独使用可

### 背景
NVIDIA/Noetraニュース記事の検証で、圧縮率が約19%と低かった（通常35〜40%）。
主因は正式名称の保護規則が正しく機能した結果であり適正だが、
「産総研（AIST）」のように**原文自身が略称を与えている**場合まで
BRIEFで正式名称を繰り返すのは冗長。原文由来の略称は「独自略記の発明」に
当たらないため、BRIEFでの単独使用を許可する。

### 追加規則（略語セクションに1行）
```
- If SOURCE itself introduces an acronym for a name ("full name (ABBR)"
  style, e.g. 産業技術総合研究所（産総研/AIST）), FULL_TEXT keeps
  "full name (ABBR)" at first mention as usual, and BRIEF_TEXT may use
  the ABBR alone (National Institute of Advanced Industrial Science and
  Technology (AIST) -> AIST). This applies ONLY to acronyms the source
  provides - never invent or import one the source does not give.
```
- 対象は原文が括弧等で明示した略称のみ。社名の一般的短縮
  （Sony Group Corporation → Sony 等）は引き続き禁止（固有名詞保護の
  現行規則を維持。V91.29検討時の決定通り、選択肢②は不採用）。
