## 2-1. 追加で完了した品質単位（V9188 / V9189）

上の4件とは別に、次の2単位を実装し、実画面を含む回帰で確認した。

### エディタの言語と標準スペルチェック（V9188）

- ルートのUI言語は `ja` のまま。
- `to_en` は source を `ja`、target を `en` とする。
- `to_jp` は source を `en`、target を `ja` とする。
- target の textarea は `spellcheck=true`。行の日本語アクセシブル名も保持する。
- 画面に見えるスペルの助けは、Edge/OS にその言語の辞書がインストールされている場合の
  ネイティブ機能に依存する。市販の翻訳支援ツールと同等の完全なスペルチェッカーを
  実装・検証したという意味ではない。

### 一括置換の一手 undo（V9189）

- 置換前のスナップショットはサーバが所有し、直前の一括置換1回だけを戻せる。
- 対象行だけの可変セグメント状態を正確に戻す。対象は translation、masked translation、
  origin、state、confirmed、QC 状態・入力世代・fingerprint・findings、TM 登録状態、
  reference usage/events、terminology usages/exceptions/generation であり、source は
  書き戻さない。対象外の行と source は変更しない。
- ExpectedRevision の CAS、project lock、generation/manifest の atomic な保存を通して
  永続化するため、再起動後も undo できる。保存・mutation が失敗した場合は元の undo を
  保持し、後続の成功した mutation は無効化する。2回目の replace は1回目の undo を
  上書きする。
- `search_replaced` の監査イベントは残し、undo は `search_replace_undone` を追記する。
- 画面には件数付きの「直前の一括置換を元に戻す（N行）」操作を表示する。
- スナップショットは最大512行・1 MiB。上限超過は mutation 前に失敗し、部分置換を残さない。
