# YakuLingo V91.43 実装記録

作成日: 2026-07-21

V91.43では、テキスト翻訳プロンプトのR3およびSOURCE内ラベルの扱いに関する自己矛盾を除去し、V91.42で追加したFULL出力のFIs展開後処理を削除した。これにより、翻訳出力をコードで書き換えず、FULLとBRIEFの略語差をプロンプト上で整合的に扱う構成へ戻した。

本版をもって翻訳品質の改善サイクルを凍結する。以後対応するのは、①数値・事実の誤り、②翻訳が完走しない障害、③利用者（財務本部長等）からの明示的な指摘、の3条件のみとする。文体・略語・表記の揺れ（FIs/FIのFULL出現、命令形、vol./volume揺れ、and/&揺れ、glossaryケース差のconflicted WARN等）は仕様として受容する。数値の正しさは前処理とコード監査で保証し、プロンプト遵守には依存しない。
