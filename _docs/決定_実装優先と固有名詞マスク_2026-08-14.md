# 決定: 制約文と実装が食い違うときは実装を採る（2026-08-14）

利用者の判断。3件を決めた。以降、この3件を議論し直さない。

## 1. CLAUDE.md より実装を優先する

制約文と実装が食い違っている箇所は、**実装が正**とする。制約文のほうを直す。

これは「制約を緩めてよい」という意味ではない。**どちらが現に動いているかを基準にする**という意味である。
実装を制約文へ合わせて変える改修は、この決定を根拠にしては行わない。

### 何が食い違っていたか（実装を読んで確認した）

CLAUDE.md は「書き戻しDRAFTを止めるのは2つだけ（訳文が空 / 数字の点検に落ちる）」と書く。
`Get-YakuCatOutputEligibility`（`src/CatProject.ps1`）が実際に積む理由は **3種類**である。

| 理由 | 条件 |
| --- | --- |
| `segment-untranslated` | 訳文が空 |
| `segment-qc-not-current` | 確定済みだが用語スナップショットが変わり、点検が古い |
| `segment-qc-failed` | `Invoke-YakuCatSegmentValidation` の error 重大度が1件以上 |

3つ目は数値だけではない。error 重大度が付くのは数値系のほか
`currency-mismatch`、`structure-integrity`、`structure-validation-error`、
`terminology-conflict`、`terminology-forbidden`、`terminology-missing` である。

**コード内のコメントも同じくずれている。** `src/CatProject.ps1` の
「残す歯止めは2つだけにする」というコメントは、その直下のコードが3種類の理由を
積むことと一致していない。CLAUDE.md を直すときに、このコメントも直す。

### 実装を優先した結果、変わらないもの

- 未確認は止めない（実装どおり。件数を画面と文書内の帯に出す）
- 数値が抜けた訳は欠陥として止める（実装どおり）
- 用語・構造・通貨でも止まる（実装どおり。**これが新しく明文化される部分**）

### 残る宿題

止まった理由が画面に出るとき、用語で止まっても「数字」の話をされる。
`Get-YakuCatOutputPreflight` の文言を finding コードの種別ごとに分ける。
これは実装を制約文へ合わせる改修ではなく、実装の説明能力の不足なので、この決定とは独立に直す。

**2026-08-15 追記。** 分けた（`dca2558`）。error コードは構文木で数え直して**18種**あり、
それぞれに文言がある。あわせて、この節が当初書いていた `Get-YakuCatExportPreflight` という
関数が**実在しない**ことが分かったので名前を訂正した（実体は `Get-YakuCatOutputPreflight`。
誤った名前はこの文書と CLAUDE.md の2箇所にしか無く、コードには0件だった）。

宿題は半分残っている。新しい文言が案内する「点検の指摘」が、その場面の画面に無い。
QcFindings を実セグメントへ書くのは確定処理だけで、書き出し前点検は写しに走らせるため
1件も残らず、`cat.js` は件数0でそのボタンを隠す。

## 2. 固有名詞マスクは「制約文が古い」

CLAUDE.md の「外部送信前のマスクを外さない。数値・**固有名詞**」のうち、
固有名詞は**実装されたことがなく、実装する予定も無い**。制約文が古い。

### 根拠（実装を読んで確認した）

- `[[P` 形式のプレースホルダは `src/` `www/` `tools/` のどこにも存在しない
- `src/Server.ps1` の開示文は「本文、固有名詞、見出し、原文と訳文は校正に必要なため送信内容に残ります」と
  明示している。意図して書かれた文である
- `tools/Test-YakuV9160NumericMasking.ps1` は「補助欄の固有名詞はマスクしない」を assert している

### やること

1. CLAUDE.md の当該行から「固有名詞」を外す。マスクの対象は**数値のみ**と書く
2. `www/assets/cat.js` の QC ラベル `proper-noun-missing`（「会社名や人名が訳文に入っていないようです」）を**削除する**。
   `src/` に生成箇所が1件も無い死語であり、残すと固有名詞の点検があるように読める
3. 2 が再発しないよう、**cat.js の QC ラベルに `src/` が生成しないコードが無いこと**を機械で固定する。
   走査は素の grep ではなく AST で関数本体を切り出して行う（`Code='` の grep は `ErrorCode` を巻き込む）。
   固定する前に、既知のコードを1つ故意に消すと必ず赤になることを確かめる

### 変わらないもの

数値マスクは従来どおり。`Assert-YakuNumericPromptProtected` の fail-closed の門も従来どおり。
**この決定は数値マスクを一切緩めない。**
