## §2 今日わかった重大なこと

### 実数値と人名が Copilot へ出ていた（直した）

CAT の「残りを訳す」が、未公開の数値と人名を素のまま送っていた。
組み立てたプロンプトの実物:

    [[ID:1]] 1. 営業利益は115.77億円、毛籠社長が発表しました。

マスクは `Invoke-YakuCatCopilotPass` に入っていたが、**呼び出し元が0件**だった。
ジョブは別ランスペースで走るので Project を受け取る関数を呼べず、同じ処理が
`Server.ps1` に書き直され、そこにマスクが無かった。
朝のコミット「CAT 経路が数値をマスクせずに送っていたのを直した」は誤りで、
直した先が死んだ関数だった。

**統制テストも通っていた。** `CatProject.ps1` の本文を grep していたので、
死んだ関数に一式が揃っていれば合格になる。送信経路の一覧も
「`Invoke-YakuCopilotPrompt` というリテラルを含むファイル」から作っていたので、
中継関数を呼ぶだけの `Server.ps1` は最初から現れなかった。

いまは中継関数を「自分で伏せるもの」と「呼び出し側に任せるもの」に分けて見る。
ジョブ側のマスクを外して、検査が落ちることを確かめてある。

### 固有名詞の記号が数値マスクに壊されていた（直した）

`[[P1]]社長` → `[[P[[N2]]]]社長`。復元が数値→固有名詞の順なので偶然もとに戻り、
気づかなかった。伏せた件数の水増し、名前についての数値警告、モデルが形を
整えたときの名前の消失、という害がある。

### 金額の billion 表記が10倍ずれる（選べないようにした）

`122億円` → `¥122 billion`（正しくは `¥12.2 billion`）。
プロンプトは「桁の換算は呼び出し側でやる」と書いているが、`rescale` は
**プロンプトの文字列にしか存在しない**。換算はロードマップ第2段階で入れる。
戻し方は `Settings.ps1` と `PromptBuilder.ps1` のコメントに書いた。

### 「Copilot は120回で止まる」は誤り

ログから数えたら**最初の失敗は184回目**だった。読めるのは
「短時間に集中して送ると弾かれ、間を置けば戻る」まで。
窓の長さも境目も確かめていない。詳細はロードマップ §5-4。

利用者の見立て（未確認）: 同じ M365 アカウントで別のアプリが同時に画像を
Copilot へ送っていたことが効いていた可能性がある。画像の送信をやめてからは
弾かれていない。
