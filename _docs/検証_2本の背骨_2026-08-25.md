# 2本の背骨とリリース検証

## 利用者に見せる背骨

1. テキスト: 貼る → 数字をマスク → 訳す → コピー
2. ファイル: ファイル → 過去の確定対訳で入力 → 残りを一行ずつ訳して確定 → 書き出す

用語集の `cell-exact` は独立した利用概念にしない。従来CSVを供給元として残し、過去の
確定対訳と同じ決定的な完全一致代入へ統合する。検索、分割、結合、用語編集、原文更新、
危険操作は背骨の主画面から隠す。

## リリース検証の定義

リリース可否の「検証済み」は、上記2経路を実アプリ・実ブラウザで入口から出口まで各1周し、
次を確認した状態だけを指す。

- テキスト: 既定の短い1案、もっと短く、全文、oku/billionのローカル切替、コピー、計測記録
- ファイル: 読み込み、確定対訳代入、未訳行の翻訳と確定、oku/billionのプロジェクト内切替、書き出し
- 共通: 数値が外部送信前にマスクされ、画面に背骨外操作が露出しない

静的試験、単体試験、画面寸法測定だけでは「検証済み」としない。
