# V91.57 修正指示書
## 販促費関連用語のFULL／BRIEF整理および「子会社 固定販促費」の完全一致追加

## 1. 修正目的

販促費関連の英訳について、現在は以下の表記が混在している。

- `fixed sales promotion costs`
- `Fixed MKT`
- `Fixed Marketing`
- `promotion costs`

特に `MKT` は marketing 全般を意味し、`promotion costs` より範囲が広いため、販促費の略語としては意味が曖昧になりやすい。

今回、次の原則に整理する。

- **FULL**：販促費を省略せず、`sales promotion costs` を使用する。
- **BRIEF**：販促費を `promo. costs` と略す。
- **ファイル翻訳の表項目用完全一致**：表見出しとして指定された固定訳をそのまま使用する。
- 既存の `MKT`／`Marketing` 表記は、販促費を意味する登録について順次廃止する。

併せて、ファイル翻訳の表項目用完全一致として、次を追加する。

```text
子会社 固定販促費 → Subs. Fixed Promo. Costs
```

## 3. 用語の基本方針

### 3.1 FULL

| 日本語 | FULLの標準訳 |
|---|---|
| 販促費 | sales promotion costs |
| 販売促進費 | sales promotion costs |
| 固定販促費 | fixed sales promotion costs |
| 子会社固定販促費 | subsidiaries' fixed sales promotion costs |
| 子会社 固定販促費 | subsidiaries' fixed sales promotion costs |

FULLでは、次の略語を原則として使用しない。

- `MKT`
- `Marketing`（販促費の省略表現としての使用）
- `Promo.` 単独
- `Promo. Costs`

文章中では、文脈に応じて単数・複数、所有格、冠詞を自然に調整してよい。

例：

```text
固定販促費の増加
→ an increase in fixed sales promotion costs
```

```text
子会社の固定販促費
→ subsidiaries' fixed sales promotion costs
```

---

### 3.2 BRIEF

| 日本語 | BRIEFの標準訳 |
|---|---|
| 販促費 | Promo. Costs |
| 販売促進費 | Promo. Costs |
| 固定販促費 | Fixed Promo. Costs |
| 子会社固定販促費 | Subs. Fixed Promo. Costs |
| 子会社 固定販促費 | Subs. Fixed Promo. Costs |

表項目・グラフ項目・短い注記では、上記の大文字表記を使用する。

文章中で小文字が自然な場合は、次も許容する。

```text
promo. costs
fixed promo. costs
```

ただし、一つの表・グラフ内では大文字・小文字を混在させないこと。

## 4. `prompt_glossary.csv` の修正

対象：

```text
V91.57/app/prompt_glossary.csv
```

### 4.1 既存の固定販促費登録を修正

現在：

```csv
固定販促費,fixed sales promotion costs|fixed MKT
```

修正後：

```csv
固定販促費,fixed sales promotion costs|fixed promo. costs
```

候補順は必ず次の意味を持たせる。

1. 先頭：FULL用の自然な展開形
2. 2番目：BRIEF用の承認済み略語形

### 4.2 販促費関連語を追加または整理

以下の登録が存在しない場合は追加する。

```csv
販促費,sales promotion costs|promo. costs
販売促進費,sales promotion costs|promo. costs
```

「販促費」と「販売促進費」は同じ標準訳に統一する。

### 4.3 子会社との複合語を追加

```csv
子会社固定販促費,subsidiaries' fixed sales promotion costs|subs. fixed promo. costs
子会社 固定販促費,subsidiaries' fixed sales promotion costs|subs. fixed promo. costs
```

空白あり・空白なしの両方を登録し、入力表記の差で訳が揺れないようにする。

ただし、プロンプト生成時に日本語の空白が正規化され、両者が同一キーとして衝突する実装である場合は、重複登録せず正規化後の1件だけとする。

## 5. `glossary.csv` の修正

対象：

```text
V91.57/app/glossary.csv
```

`glossary.csv` はファイル翻訳の表項目用完全一致に使用されるため、出力したい固定訳を第2列の先頭に置くこと。

### 5.1 既存の固定販促費を変更

現在：

```csv
固定販促費,Fixed MKT
```

修正後：

```csv
固定販促費,Fixed Promo. Costs
```

### 5.2 販促費関連語を追加

存在しない場合は、以下を追加する。

```csv
販促費,Promo. Costs
販売促進費,Promo. Costs
```

### 5.3 「子会社 固定販促費」の完全一致を追加

以下を追加する。

```csv
子会社 固定販促費,Subs. Fixed Promo. Costs
```

入力データで空白なしの表記も使用される可能性があるため、必要に応じて次も追加する。

```csv
子会社固定販促費,Subs. Fixed Promo. Costs
```

ただし、完全一致処理の前に空白除去または空白正規化が実施される場合は、キー重複を避けるため片方だけにする。

### 5.4 既存複合語の表記を統一

現在：

```csv
販売奨励金/固定販促費,VM / Fixed Marketing
```

修正後：

```csv
販売奨励金/固定販促費,VM / Fixed Promo. Costs
```

`Fixed Marketing` は販促費より意味が広いため、この用途では使用しない。

In FULL mode, expand Promo. Costs, Fixed Promo. Costs, and MKT when they refer to sales promotion costs.
Use “sales promotion costs” or “fixed sales promotion costs.”
Do not output “MKT” merely as an abbreviation of promotion costs.

### FULL例

## 8. 完全一致の優先順位

ファイル翻訳では、次の順序を維持する。

1. 表項目用完全一致
2. 長い複合語の用語集一致
3. 単語単位の用語集注入
4. Copilotによる通常翻訳

そのため、次のセルは単語分割せず、完全一致結果を使用すること。

```text
子会社 固定販促費
```

期待結果：

```text
Subs. Fixed Promo. Costs
```

次のような合成結果にしないこと。

```text
subs. Fixed Promo. Costs
Subsidiaries Fixed Promo. Costs
Subs. Fixed MKT
Subs. Fixed Marketing
Subsidiaries' fixed sales promotion costs
```

最後の `Subsidiaries' fixed sales promotion costs` はFULL文章としては正しいが、今回追加する表項目用完全一致の期待値ではない。

## 9. 競合・回帰防止

### 9.1 `MKT` の扱い

以下のように、明確に marketing を意味する既存用語は変更しない。

```text
marketing
marketing expenses
marketing activities
marketing strategy
```

今回変更するのは、**日本語の「販促費」「販売促進費」「固定販促費」に対して `MKT` または `Marketing` を略訳として使用している登録のみ**とする。

### 9.2 `promotion` 単独

以下は費用項目ではないため、`Promo. Costs` に置換しない。

```text
販売促進活動
販促施策
プロモーション
販売促進キャンペーン
```

これらは文脈に応じて、次のように訳す。

```text
sales promotion activities
promotional measures
promotion
sales promotion campaign
```

### 9.3 大文字・空白

完全一致の固定訳は、次の表記を厳守する。

```text
Subs. Fixed Promo. Costs
```

- `Subs.` の後に半角空白1つ
- `Fixed`、`Promo.`、`Costs` の各語間に半角空白1つ
- `Promo.` のピリオドを省略しない
- `Costs` は複数形

## 11. 文字コード・CSV保存

- `glossary.csv` と `prompt_glossary.csv` は、既存ファイルと同じ文字コードで保存する。
- UTF-8 BOMを使用している場合はBOMを維持する。
- カンマを含む訳語を追加する場合はCSVクォートを適切に使用する。
- 改行コードも既存ファイルに合わせる。
- Excelで開いて保存し直し、文字化けや列ずれを発生させないこと。

## 12. 完了条件

以下をすべて満たした場合に修正完了とする。

1. FULLで `固定販促費` が `fixed sales promotion costs` と展開される。
2. BRIEFで `固定販促費` が `Fixed Promo. Costs` となる。
3. ファイル翻訳の完全一致で `子会社 固定販促費` が `Subs. Fixed Promo. Costs` となる。
4. 販促費の意味で `MKT`、`Fixed MKT`、`Fixed Marketing` が出力されない。
5. marketing本来の意味で使用される既存用語には影響しない。
6. `販売奨励金/固定販促費` が `VM / Fixed Promo. Costs` となる。
7. 既存の数式保護、数値監査、ファイル保存、翻訳ステータス処理に回帰がない。
8. バージョン番号と変更履歴がV91.57に更新されている。
