# V91.56 修正指示書：FULL一般略語展開・BRIEF略語徹底

## 1. 目的

ECM資料英訳ツールのFULLとBRIEFの役割を、次のように明確に分離する。

- **FULL**：自然で正式なビジネス英語を優先し、一般語・社内便宜略語はできるだけ展開する
- **BRIEF**：情報を削らず、標準略語を積極的かつ一貫して使用する

今回の主要対象は「固定費」だが、同じ考え方を「変動費」その他の一般語略語にも適用する。

基本方針：

| 日本語・概念 | FULL | BRIEF |
|---|---|---|
| 固定費 | fixed costs / fixed cost | FC |
| 変動費 | variable costs / variable cost | VC |
| 固定費・変動費 | fixed and variable costs | FC & VC |
| 固定費削減 | fixed-cost reduction / reduction in fixed costs | FC redn. |
| 変動費削減 | variable-cost reduction / reduction in variable costs | VC redn. |
| 変動利益 | variable profit | VP |
| 車両変動利益 | vehicle variable profit | VP (Veh.) |

ただし、一般に定着した財務・会計略語、正式名称、原文で明示された略語は、FULLでも無条件に展開しない。

## 3. 現状確認

### 3.1 FULL展開ルール自体は存在する

`app/prompts/text_translate_to_en.txt` には、すでに次の趣旨の規則がある。

```text
The FULL spelled-out form and its BRIEF abbreviation count as the same rendering.
When a glossary entry lists both a spelled-out form and an abbreviation as variants,
FULL uses the spelled-out variant and BRIEF uses the abbreviation.
```

また、FULLについて次の規則がある。

```text
FULL_TEXT: natural business English ...; spell out BRIEF-list abbreviations.
```

したがって、プロンプトの基本設計は正しい。

### 3.2 用語集に略語のみの登録が多い

一方、`app/glossary.csv` および `app/prompt_glossary.csv` には、次のように略語のみを候補とする項目がある。

```csv
変動利益,VP
車両変動利益,VP (Veh.)
フリーキャッシュフロー,FCF
```

現行FULLルールには「abbreviation-only glossary terms stay abbreviated in both outputs」という例外があるため、略語しか登録されていない一般語はFULLでも略語のままになる。

### 3.3 固定費と変動費のBRIEF略語が未整備

現行の `style_brief_rules.txt` には `FC` と `VC` がStandard abbreviationsとして登録されていない。

また、現行例文は次のようになっている。

```text
FULL “Fixed-cost reduction ...”
-> BRIEF “Fixed cost redn. ...”
```

BRIEFとしては `FC redn.` の方が整合的である。

## 4. 最終仕様

### 4.1 FULLの原則

FULLでは、次に該当する略語を原則として展開する。

1. 一般英単語を短縮したBRIEF専用略語
2. 社内資料上の便宜略語
3. 用語集に展開形を追加できる管理会計用語
4. 初見の外部読者には意味が通じにくい略語

例：

```text
FC       -> fixed costs / fixed cost
VC       -> variable costs / variable cost
VP       -> variable profit
VP (Veh.) -> vehicle variable profit
redn.    -> reduction
vol.     -> volume
fcst.    -> forecast
act.     -> actual
consol.  -> consolidated
Suppl.   -> supplementary materials
```

FULLでは、文章の文法と数に合わせて単数・複数を選択する。

```text
固定費が増加した。
-> Fixed costs increased.

固定費1項目
-> a fixed cost item
```

### 4.2 BRIEFの原則

BRIEFでは、Standard abbreviationsに登録した語を必ず略語化する。

```text
fixed costs / fixed cost -> FC
variable costs / variable cost -> VC
variable profit -> VP
vehicle variable profit -> VP (Veh.)
reduction -> redn.
```

同じBRIEF出力内で、次のような表記揺れを発生させない。

```text
FC / Fixed Cost / Fixed Costs
VC / Variable Cost / Variable Costs
VP / Variable Profit
```

原則として、BRIEFではそれぞれ `FC`、`VC`、`VP` に統一する。

### 4.3 FULLでも略語を維持する例外

次はFULLでも略語を維持してよい。

#### A. 一般に定着した財務・会計略語

例：

```text
EBITDA
EPS
ROE
ROA
ROIC
FCF
SG&A
R&D
D&A
P&L
B/S
C/F
A/R
A/P
NWC
CAPEX / OPEX
COGS
```

ただし、既存仕様で別の正式表記が定められているものは、その仕様を優先する。

#### B. ECM資料で正式に使用している指標名

例：

```text
OP
ROS
VP
MC
```

ただし `VP` は外部向けFULLとして分かりにくいため、今回の修正では原則として展開候補を追加する。後述の用語集修正に従うこと。

`OP` については、ECM資料で指標名として定着している場合はFULLでも維持してよい。一般文章中で自然な英文が求められる場合の扱いは、既存の用語集・プロンプトを優先する。

#### C. 原文が略語そのものを示している場合

```text
フリーキャッシュフロー（FCF）
-> free cash flow (FCF)
```

初出で正式名称と略語が併記されている場合、FULLは正式名称＋略語を保持する。

#### D. 固有名詞・正式名称・用語集固定語

会社名、製品名、制度名、正式な表見出しなどを機械的に展開しない。

## 5. ファイル別修正内容

### 5.1 `app/prompt_glossary.csv`

#### 5.1.1 固定費

変更前：

```csv
固定費,fixed costs|fixed cost
```

変更後：

```csv
固定費,fixed costs|fixed cost|FC
```

**展開形を先頭に置くこと。**

理由：

- FULLは先頭の展開形を使用できる
- BRIEFはプロンプト規則により `FC` を選択できる
- `FC` を先頭にするとFULLにも流入するおそれがあるため、先頭にはしない

#### 5.1.2 変動費用

変更前：

```csv
変動費用,variable cost
```

変更後：

```csv
変動費用,variable costs|variable cost|VC
```

#### 5.1.3 固定費・変動費

変更前：

```csv
固定費・変動費,fixed and variable costs|fixed- and variable-cost|fixed and variable cost|fixed & variable cost|fixed- & variable-cost
```

変更後：

```csv
固定費・変動費,fixed and variable costs|fixed and variable cost|fixed- and variable-cost|FC & VC|FC/VC
```

FULLでは `fixed and variable costs` を優先し、BRIEFでは `FC & VC` を優先する。

#### 5.1.4 変動利益

変更前：

```csv
変動利益,VP
```

変更後：

```csv
変動利益,variable profit|VP
```

#### 5.1.5 車両変動利益

変更前：

```csv
車両変動利益,VP (Veh.)
```

変更後：

```csv
車両変動利益,vehicle variable profit|VP (Veh.)
```

#### 5.1.6 変動利益単価等

略語しか登録されていない次の項目も、展開形を先頭に追加する。

例：

```csv
変動利益単価,variable profit per unit|VP per unit
台当り変動利益,variable profit per unit|VP per unit
台当り車両変動利益単価,vehicle variable profit per unit|VP (Veh.) per unit
車両変動利益単価,vehicle variable profit per unit|VP (Veh.) per unit
```

同義語間の既存整合を崩さないこと。

### 5.3 `app/prompts/style_brief_rules.txt`

#### 5.3.1 Standard abbreviationsへ追加

Standard abbreviationsに次を追加する。

```text
FC, VC, VP
```

対応関係も明記する。

```text
fixed costs / fixed cost -> FC
variable costs / variable cost -> VC
variable profit -> VP
vehicle variable profit -> VP (Veh.)
```

#### 5.3.2 強制使用ルール

次の趣旨を追加する。

```text
In BRIEF, use FC for fixed costs/fixed cost, VC for variable costs/variable cost,
and VP for variable profit. Use VP (Veh.) for vehicle variable profit.
Do not mix abbreviated and spelled-out forms in the same BRIEF output unless a glossary-fixed formal term requires otherwise.
```

#### 5.3.3 例文修正

変更前：

```text
FULL “Fixed-cost reduction of 0.5 oku improved ROS by 0.5 points, back to the level before additional tariffs.”
-> BRIEF “Fixed cost redn. 0.5 oku: +0.5 pts to ROS, back to pre-additional-tariff level.”
```

変更後：

```text
FULL “Fixed-cost reduction of 0.5 oku improved ROS by 0.5 points, back to the level before additional tariffs.”
-> BRIEF “FC redn. 0.5 oku: +0.5 pts to ROS, back to pre-additional-tariff level.”
```

追加例：

```text
FULL “Variable costs increased due to higher material prices.”
-> BRIEF “VC up on higher material prices.”

FULL “Variable profit decreased by 3.0 oku due to lower volume.”
-> BRIEF “VP down 3.0 oku on lower vol.”

FULL “Fixed and variable costs increased.”
-> BRIEF “FC & VC up.”
```

### 5.4 `app/prompts/text_translate_to_en.txt`

既存のR3およびFULL_TEXT規則を強化する。

次の趣旨を明記する。

```text
FULL must spell out ordinary-word and internal shorthand abbreviations whenever a spelled-out glossary variant exists.
BRIEF must use the approved abbreviation when one exists.
Glossary candidate order does not by itself authorize an abbreviation in FULL.
```

さらに、次の対比を明記する。

```text
FULL: fixed costs, variable costs, variable profit, vehicle variable profit
BRIEF: FC, VC, VP, VP (Veh.)
```

現行の次の例外文：

```text
abbreviation-only glossary terms (e.g. FCF, OP) stay abbreviated in both outputs
```

は、次の趣旨に修正する。

```text
Abbreviation-only glossary terms stay abbreviated in both outputs only when they are approved financial acronyms, formal metric names, proper nouns, or source-defined abbreviations.
Do not treat ordinary-word or internal shorthand abbreviations as FULL-safe merely because the glossary currently lists only the abbreviation.
```

これにより、用語集の登録漏れを理由に一般略語がFULLへ残ることを防ぐ。

## 6. 用語集全体の略語監査

固定費・変動費だけでなく、`glossary.csv` と `prompt_glossary.csv` の全行を監査する。

### 6.1 監査対象

以下に該当する略語のみ登録を抽出する。

- 英訳候補が大文字略語のみ
- `.` を伴う短縮語のみ
- 括弧付き略語のみ
- 外部読者に意味が伝わりにくい社内略語

例：

```text
VP
VP (Veh.)
Var.
Fcst.
Cons.Adj.
P/U
I/(D)
```

### 6.2 各用語の分類

各略語を次の3分類に分ける。

#### 分類A：FULLでも維持

- 定着した財務略語
- 正式指標名
- 固有名詞
- 原文定義済み略語

#### 分類B：FULLでは展開、BRIEFでは略語

- 固定費 `fixed costs / FC`
- 変動費 `variable costs / VC`
- 変動利益 `variable profit / VP`
- forecast / fcst.
- volume / vol.
- consolidated / consol.
- supplementary materials / Suppl.

#### 分類C：用語集固定のため個別判断

- 表の列幅や既存帳票名に依存するもの
- 社内固有の管理会計指標
- 展開すると意味が変わる可能性があるもの

### 6.3 変更方針

分類Bについては、原則として次の形式へ変更する。

```csv
日本語,FULL展開形|BRIEF略語
```

例：

```csv
変動利益,variable profit|VP
固定費,fixed costs|fixed cost|FC
変動費用,variable costs|variable cost|VC
```

一括置換は行わず、用語単位で確認すること。

## 7. 用語選択の優先順位

1. 原文に明示された正式名称＋略語
2. より長い用語集の完全一致・最長一致
3. 個別登録された正式名称・指標名
4. FULL/BRIEFモード別の候補選択
5. 一般的な略語展開・圧縮規則

例：

```text
固定費
FULL  -> Fixed Costs / fixed costs
BRIEF -> FC

固定費率
FULL  -> Fixed Cost Ratio
BRIEF -> FC Ratio（BRIEF規則を適用する場合）
```

ただし、既存用語集で `Fixed Cost Ratio` を固定語として保持する必要がある場合は、BRIEFでもそのままとする。どちらを採るかは用語集固定語の優先順位に従い、同一資料内で揺らさない。

## 8. 回帰テスト

### 8.1 固定費

入力：

```text
固定費が増加した。
```

期待FULL：

```text
Fixed costs increased.
```

期待BRIEF：

```text
FC up.
```

FULL不許可：

```text
FC increased.
```

BRIEF不許可：

```text
Fixed costs increased.
Fixed cost up.
```

### 8.2 変動費

入力：

```text
原材料価格の上昇により変動費が増加した。
```

期待FULL：

```text
Variable costs increased due to higher material prices.
```

期待BRIEF：

```text
VC up on higher material prices.
```

### 8.3 固定費・変動費

入力：

```text
固定費・変動費ともに増加した。
```

期待FULL：

```text
Both fixed and variable costs increased.
```

期待BRIEF：

```text
FC & VC both up.
```

### 8.4 変動利益

入力：

```text
販売台数の減少により変動利益が3億円減少した。
```

期待FULL：

```text
Variable profit decreased by 3 oku due to lower sales volume.
```

期待BRIEF：

```text
VP down 3 oku on lower sales vol.
```

FULL不許可：

```text
VP decreased by 3 oku.
```

### 8.5 車両変動利益

入力：

```text
車両変動利益単価
```

期待FULL：

```text
Vehicle Variable Profit per Unit
```

期待BRIEF：

```text
VP (Veh.) per unit
```

### 8.6 定着略語の保護

入力：

```text
EBITDA、FCF、ROE
```

期待FULL・BRIEF：

```text
EBITDA, FCF, ROE
```

これらを不必要に長文化しない。

### 8.7 混在防止

同一BRIEF出力に以下が混在しないこと。

```text
FC / Fixed Cost
VC / Variable Cost
VP / Variable Profit
```

同一FULL出力では、一般語について次が混在しないこと。

```text
fixed costs / FC
variable costs / VC
variable profit / VP
```

ただし、正式名称＋略語の初出定義は例外とする。

## 12. 完了条件

以下をすべて満たした場合に完了とする。

1. FULLで `固定費` が `fixed costs / fixed cost` になる
2. BRIEFで `固定費` が `FC` になる
3. FULLで `変動費` が `variable costs / variable cost` になる
4. BRIEFで `変動費` が `VC` になる
5. FULLで一般語の `VP` が原則 `variable profit` に展開される
6. BRIEFで `variable profit` が `VP` に統一される
7. 定着した財務略語は不必要に展開されない
8. 同一出力内で展開形と略語が不自然に混在しない
9. 既存の用語集固定語、数値監査、構造監査を壊さない
10. 全回帰テストが成功する
